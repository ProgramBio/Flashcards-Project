# Witch's Memo
โปรเจกต์ Witch's Memo คือโปรเจกต์เกมที่พัฒนาขึ้นด้วย Pygame ซึ่งจะเปลี่ยนการท่องจำคำศัพท์ ให้กลายเป็นเกมต่อสู้ RPG สไตล์ Turn-based โดยผู้เล่นจะต้องสร้าง Deck คำศัพท์ของตัวเอง หรือ Deck เริ่มต้นที่มีให้ และนำไปต่อสู้กับมอนสเตอร์ โดยใช้ระบบการลากการ์ดเพื่อแสดงว่าผู้เล่น "จดจำ" หรือ "ลืม" คำ ๆ ศัพท์นั้นด้วยความซื่อสัตย์ของตนเอง

---

## Features
-สรุปฟีเจอร์หลัก ๆ ของโปรเจกต์ เช่น
* **ระบบการต่อสู้หลัก :** -ผู้เล่นลากการ์ดไปทางขวาเพื่อแสดงว่าผู้เล่นจดจำคำๆนั้นได้ หรือลากการ์ดไปทางซ้ายเพื่อแสดงว่าผู้เล่นจดจำคำๆนั้นไม่ได้
* **ระบบตอบถูกต่อเนื่องและระบบสกิล :** หากผู้เล่นทำการตอบถูกต่อเนื่องทุก ๆ สามครั้งผู้เล่นได้จะรับแต้ม (SP) สำหรับการใช้สกิล
* **ระบบสกิล :**
    * **Heal :** ใช้หนึ่ง (SP) เพื่อฟื้นฟูเลือด
    * **Shield :** ใช้สอง (SP) เพื่อป้องกันความเสียหายหนึ่งครั้ง
    * **Freeze :** ใช้สอง (SP) เพื่อหยุดเวลานับถอยหลังในเทิร์นนั้น
    * **Max HP Up :** ใช้หนึ่ง (SP) กดสองครั้งเพื่อเพิ่มเลือดสูงสุด
* **ศัตรู:** ต่อสู้กับมอนสเตอร์หนึ่ง, สอง, หรือสามตัว ขึ้นอยู่กับด่านที่ผู้เล่นทำการเลือก โดยด่านที่มีให้เลือกจะขึ้นอยู่ที่จำนวนคำที่ผู้เล่นมีใน Deck และมีเวลานับถอยหลังซึ่งผู้เล่นสามารถปรับเปลี่ยนได้ที่ตั้งค่า  หากผู้เล่นมีจำนวนคำเต็มสามสิบคำ ผู้เล่นจะสามารถเลือกต่อสู้กับบอสได้ โดยบอสจะมีเวลานับถอยหลังเป็นจำนวนเต็มของครึ่งหนึ่งของเวลานับถอยหลัง

### ระบบ Deck
ผู้เล่นสามารถ **สร้าง**, **แก้ไข**, **เปลี่ยนชื่อ**, **เลือกหน้าปก**, และ **ลบ** Deck หรือ คำศัพท์ได้

### ระบบตั้งค่า
* **ระบบเสียงพื้นหลัง :** ปรับระดับเสียงเพลงประกอบ
* **คำแนะนำ :** เปิด/ปิด คำแนะนำระหว่างเปลี่ยนฉาก
* **เวลาตอบคำถาม :** ปรับเวลาที่ใช้ในการตอบคำถาม
* **รูปแบบตัวอักษร:** เลือกรูปแบบตัวอักษรระหว่าง `fs-gravity.otf`(ค่าเริ่มต้น) หรือ `Pixel/SansThai.ttf` ผสมกับ `Pixel/PixelMedium.ttf` (ฟอนต์ทางเลือกที่อ่านง่ายกว่า)

## Prerequisites

โปรเจกต์นี้ต้องใช้โปรแกรมและไลบรารีต่อไปนี้:
- **Python 3.x**
- **pygame**

(ไลบรารีที่จำเป็นทั้งหมด ถูกระบุไว้ในไฟล์ `requirements.txt` แล้ว)
---
## Installation

1.  **Clone Repository**
2.  **Requirement Install**: `bash pip install -r requirements.txt`
3.  **Run Game**: `bash python WitchMemo.py`

## วิธีการเล่น

1.  **สร้าง Deck:**
    * ไปที่ `PLAY` -> `FREE FOR ALL` -> `CREATE NEW DECK`
    * เลือกรูปแบบการ์ด -> ตั้งชื่อ Deck
    * คลิกที่ Deck ใหม่ -> `EDIT` -> เพิ่มคำศัพท์ (Word) และความหมาย (Meaning)
2.  **เริ่มต่อสู้:**
    * คลิกที่ Deck ที่ต้องการ -> `PLAY`
    * เลือกด่าน (เช่น 5 Cards, 10 Cards, หรือ BOSS)
3.  **ในการต่อสู้:**
    * **ลากการ์ดไปทางขวา (Know):** หากจำความหมายได้ (โจมตีมอนสเตอร์)
    * **ลากการ์ดไปทางซ้าย (Don't Know):** หากจำไม่ได้ (คุณจะโดนโจมตี)
    * **ใช้สกิล:** ตอบถูกต่อเนื่องเพื่อเก็บ SP และคลิกใช้สกิล (ใช้ได้ 1 ครั้ง/เทิร์น ก่อนลากการ์ด)
